# Brochure Design

## Procedure

1. Inventory source copy, product/company data, photography, diagrams, logos, certifications, testimonials, and missing assets. Preserve source truth.
2. Confirm or infer format, page count target, language, binding, audience, usage context, and printer constraints. Flag assumptions.
3. Build content architecture before page decoration: cover, opening, narrative sections, company proof, products/services, cases, CTA/contact, and back cover as relevant.
4. Produce a page map with page/spread purpose, primary content, image requirement, and special production notes.
5. Define an editorial system: margins, columns, baseline/rhythm, type hierarchy, image ratios, captions, tables/specs, recurring product/case modules, folios, section openers, and whitespace strategy.
6. Create 2-3 cover or visual directions only when direction is unresolved; otherwise develop the selected system.
7. Check pacing across spreads: alternate dense and quiet moments intentionally; avoid making every page a hero page.
8. Mark missing copy/images as explicit placeholders rather than inventing company facts.
9. For print output, load `print-production` before calling anything print-ready.
10. Run `visual-review` on representative spreads and the full sequence.

## Deliverables

Content audit, page map, visual/editorial direction, layout system, representative page specifications or artifacts, asset gaps, and print handoff status.

## Failure conditions

Do not force content to fit a predetermined page count by shrinking type or fabricating filler. Do not treat isolated attractive spreads as a coherent brochure if the sequence and system do not hold together.
