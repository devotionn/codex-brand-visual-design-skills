# Skills index

Default entry point: `brand-design`.

Specialists:

- `logo-design` — logo concept, lockup and reduction system
- `brand-identity` — VI / identity system
- `brochure-design` — brochures, catalogs and editorial systems
- `visual-concept` — KV, posters, campaign and effect-image concepts
- `art-direction` — moodboard and visual-language direction
- `image-prompt` — image generation/editing prompt construction
- `visual-review` — independent design critique
- `print-production` — prepress and vendor handoff

Load only the smallest set needed for the current task.
