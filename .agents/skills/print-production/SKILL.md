# Print Production

Printer/vendor requirements override generic guidance.

## Procedure

1. Read the printer's supplied specification, dieline, ICC/profile, binding method, stock, finishing notes, and export standard when available.
2. Verify actual trim/artboard size, bleed, safe area, page count/order, and binding/spine assumptions against those requirements.
3. Inspect placed image effective resolution at final size. Treat 300 ppi as a common reference for many print jobs, not a universal pass rule.
4. Check color mode/profile, spot colors, black text and rich-black usage, transparency, overprint, total-ink concerns, gradients, and effects as relevant to the print process.
5. Check fonts, embedding/outlining policy, missing links, raster/vector suitability, QR/barcode size/contrast, and dieline/finishing layers.
6. Check finishing risks: foil, spot UV, emboss/deboss, white ink, varnish, die cut, folds, creep, spine, lamination, trapping, and registration where relevant.
7. Export only to the known vendor standard. If PDF/X or another standard is not specified, do not invent a mandatory profile.
8. Record each preflight item as verified, not verified, or vendor decision. Never turn unavailable checks into PASS.

## Deliverables

Preflight checklist, blocking issues, export settings actually used or recommended, vendor questions, and handoff status.

## Failure conditions

Do not call a file print-ready solely because it is CMYK or high resolution. Do not override the printer's own specification with generic internet rules.
