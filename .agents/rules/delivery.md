# Delivery and evidence

Choose deliverables that match the requested workflow and available tools.

## Artifact levels

1. **Creative direction** — concept thesis, keywords, palette, type direction, composition rules, imagery language.
2. **Design specification** — grids, sizes, lockups, page map, reusable modules, production notes.
3. **Generated draft** — actual image, SVG, PDF, layout, or other artifact created with available tools.
4. **Editable production source** — tool-native or structured editable file when the environment supports it.
5. **Vendor-ready output** — exported against known printer/vendor requirements and actually preflighted.

Never collapse these levels into one claim. A prompt is not an image; a concept is not a finished logo; a PDF export is not automatically print-ready.

## Handoff report

When meaningful, report:

- Created
- Verified
- Not verified
- Needs decision

Include filenames, dimensions, formats, or page ranges when actual artifacts exist.
