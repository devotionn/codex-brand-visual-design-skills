# BRAND_VISUAL_DESIGN_SKILLS_V0_1_BASELINE

## Goal

Create a first usable Codex workflow for non-UI brand/graphic designers without pretending Codex replaces a designer or a native design application.

## Scope

Included:

- broad brand-design orchestration
- logo and identity workflows
- brochure/editorial planning
- KV / effect-image / campaign visual direction
- art direction and moodboards
- AI image prompting
- evidence-based visual review
- print-production handoff checks
- team usage guidance

Not yet included:

- company-specific brand assets or templates
- large design-history / style reference library
- Figma / Adobe / Blender automation
- automated raster-image quality analysis
- printer-specific profiles and dielines
- formal trademark search

## Gate for v0.1

A fresh Codex session should be able to take a real design brief, route it to the appropriate workflow, produce a structured direction or specification, state missing source inputs without fabricating them, run a separate visual review, and distinguish conceptual work from actually generated artifacts.
